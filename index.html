About

Introduction to WMS

WMS (Weather Monitoring System) is a low-cost, Arduino-based embedded system that can collect, store, process, and display local weather. It can measure Temperature, Humidity, Air Pressure, Light Intensity (Sunlight), Rain Intensity, and Altitude. By using WeatherAPI, it can obtain weather data from external meteorological data source. The API provides wind direction, wind speed and forecast weather information, which the system retrieves, processes, and displays to the user. WMS can be used by farmers, researchers, students & schools, Communities, Developers & engineers and Organizations. WMS works by collecting data from sensors and APIs, storing and processing the data, and displaying the information through a website and an LCD display. The collected data is stored in an Appwrite database and displayed on a GitHub-hosted website. The system can update the data approximately every 20 seconds and handles missing values by storing them as null.

Sensors used in WMS

  • DHT11 sensor – Temperature and Humidity sensor
  • BMP085 – Air pressure and Altitude sensor
  • LDR photoresistor – Light sensor
  • FC37 – rain sensor

How to start WMS server

  1. Install Python on your computer
  2. Create folder for WMS
  3. Open folder in a terminal
  4. Run this command: pip install appwrite requests pyserial datetime
  5. Run this command: npm install -g pm2
  6. Go to https://github.com/KidusNegatu/WMS/blob/main/WMSserver.py
  7. Copy the WMSserver.py code or download it
  8. Connect your computer to WMS
  9. Wait till you hear a beep sound
  10. Run this command: pm2 start WMSserver.py
